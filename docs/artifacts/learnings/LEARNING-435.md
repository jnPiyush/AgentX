title: Publishing a Traceable Manual VSIX
description: Keep source commits, generated instructions, package identity and manual publication boundaries aligned.
---

## Release rules

- Include shared policy changes when a shipped skill depends on them; do not
  package a newer worktree instruction than the committed source.
- Stamp the version through the repository's existing tool and verify the
  extension manifest, pack manifests and embedded runtime versions together.
- Compare the VSIX's instruction payload with the staged source, not just the
  package command's exit code. Keep draft documents and credentials outside it.
- Preserve the package checksum and commit identity. GitHub release provenance
  is generated by CI; a local build is not an attested CI artifact.
- Building and publishing a GitHub release do not authorize Marketplace upload.
  Leave the Marketplace workflow manual when the user requests manual publication.
